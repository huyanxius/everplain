Everplain 收藏助手 · macOS 自动准备

1. 解压后双击 everplain-clipper-macos.command，从官网校验并准备扩展。
   选择 1 Chrome 或 2 Edge；脚本会打开浏览器和扩展文件夹。
2. 在扩展管理页打开“开发者模式”，点击“加载已解压的扩展程序”，选择脚本打开的文件夹。
3. 在同一个浏览器用户资料中登录 https://e.qunxue.xyz 。收藏助手已预填该地址。

首次收藏会申请访问这个 Everplain 站点。只有选择导入全部书签才会申请书签权限。
不需要账号密码、Cookie 或配对码。不需要管理员权限或额外运行时。

若 macOS 不允许打开脚本、文件没有执行权限或电脑由机构管理，请停止使用脚本。
回到 https://e.qunxue.xyz/imports 选择“手动下载 ZIP”，直接解压并在浏览器加载。
不要关闭 Gatekeeper、删除隔离标记、修改企业策略或绕过警告。

固定目录：~/Library/Application Support/Everplain/Clipper/release-<校验值>
不要移动或删除已加载目录。相同版本会校验后复用；新版本会创建新目录并保留旧版。
更新需要在浏览器移除旧版、再加载新目录；移除前留意浏览器提示会清除扩展的本地设置。
脚本不会静默安装扩展，不会给所有网站授权，也不会自动更新或删除历史版本。

校验清单与 ZIP 来自同一个 HTTPS 官方站点，用于检测损坏/错版，不是独立代码签名。
