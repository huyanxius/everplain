# Everplain 产品范围

Everplain 面向需要整理资料、阅读来源和持续研究的个人用户。用户可以围绕任意主题建立私有知识库，结合自己的资料与网络来源提问，把研究过程保存为可继续的对话与文稿。

## 核心路径

1. 创建个人库并上传资料，查看处理状态，阅读原文与结构化条目。
2. 从一个问题开始研究，选择资料库，使用 Agent 检索、比较、引用和追问。
3. 打开引用核对来源，保留证据与待确认的问题。
4. 形成文稿，审阅修改建议、编辑与导出，并在之后继续工作。
5. 在账号设置管理个人资料、记忆及账号数据；管理员管理访问状态和配额。

资料库、来源、文稿和会话按账号授权。面向用户的产品没有学科、课程、竞赛或师生身份前提。品牌名为 Everplain，沿用已有标志图形及视觉基座，运行配置、账号和数据独立。

## 能力与交付边界

真实研究依赖部署者配置聊天模型、Embedding、Reranker 和网络检索。邮件验证码注册依赖验证过发信域名的 Resend；语音转写单独配置。生产配置预检不会把 Mock 当成真实模型，也不会把凭据存在当成供应商联通证明。

当前提供单实例部署资产与数据库一致备份/恢复。支付、订阅扣款、跨实例高可用、正式域名与邮件投递验证不是已经交付的事实。不得宣称已证明优于其他研究产品或完成了未执行的公网验收。
