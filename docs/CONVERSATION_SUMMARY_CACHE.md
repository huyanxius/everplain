# 真实对话摘要缓存

跨会话摘要和首页建议消费同一份经过来源验证的结构化模型结果。已有真实成功结果时，刷新、来源水位变化、调用失败或每日预算不足仍返回上次结果和原更新时间；`is_stale` 表示它与当前来源水位不同，后台状态仍可为 `pending` 或 `failed`。无成功结果时仍为空，不生成模板建议。

缓存保存在现有摘要 JSON 的 `_last_good` 字段，不增加表或迁移。每次读取检查引用消息仍属于当前账号、权限仍允许使用、引文仍存在于可读取原文；来源删除或撤销权限只移除受影响内容。正常离开最近会话窗口不移除仍可读取的旧卡片。

`conversation_summary` 使用已存在的 `actual_usage_v2` 独立交付机制。结构化内容有效时先持久缓存，再独立结算；缺失、矛盾或不满足子类型契约的 usage 标记为 `pending`，不假定为零，不回滚内容。后续真实 usage 对账仍走现有 billing attempt 和 reservation receipt。内容解析无效时不能形成成功缓存。

此改动不增加模型调用，不扩大每日预算，不释放历史未知预留。当前来源仍采用既有 16,000 字节整条消息窗口；长消息分块纳入尚未实现。已有生产零缓存不能凭此改动恢复未保存的历史响应，首次真实成功仍需正常预算准入和模型调用。
