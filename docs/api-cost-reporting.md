# 管理员 API 成本统计

入口：`/admin/api-costs`。接口：`GET /api/admin/api-costs`。只允许已登录且状态为 active 的管理员；每次请求重新核验角色。页面通过生成 SDK 读取独立只读投影，不改变计费、余额、退款、冻结或历史账本，也不调用供应商。

## 统计来源与口径

- 来源只有现有 `billing_attempts` 和 `billing_operations`。不把旧 `credit_ledger` 再加一次，也不宣称覆盖未接入该账本的全部模型、embedding、网页服务或供应商发票。
- 以调用创建时间 `created_at` 按 UTC 日期闭区间统计，默认最近 30 天，最多 366 天。迟到的已核用量会更新原调用日期下的报表，不移到核验日期。
- 可按日期、实际返回模型（缺失时回退请求模型）、供应商域名、已有端点 ID、用户 ID 分组；模型、域名、端点、用户采用精确匹配筛选。运营调用的 `operator:*` 主体也保留。
- 分组分页与汇总在同一 SQLite 只读快照内计算；汇总包含完整筛选范围。页间新调用可能改变下一次快照，刷新会读取最新值。
- `endpoint_id` 是调用端点标识，不是 API key 标识。同一端点换过 key 的历史不能反推归属。缺失供应商域名单独显示未记录。接口不读取或输出 key、配置 URL、原始 usage、请求哈希、provider request/response ID 或价格快照内容。

## 用量、参考成本和未知项

- `known` 与 `unpriced` 状态中输入、输出均已记录的调用计入确认 token；未知、预留、确定未发送不冒充零 token 的已确认调用。Tavily 等非 token 用量可能有参考成本而没有 token 明细。
- 输入 token 已包含缓存读写明细，输出 token 已包含推理明细；只以输入 + 输出作为 token 总量。缓存与推理缺字段显示未报告，部分调用有字段时显示部分报告和已报告小计。
- 参考金额仅合计 `known` 行中已持久化的 `reference_cost_pico`；不使用当前模型费率重算历史。不因回答失败或用户未扣积分排除已确认的供应商调用参考成本。
- 活跃预留与非活跃待核未知分列，均不计入已确认参考金额或实际采购。未定价用量可以有确认 token，但参考价缺失时仍保留对应预留风险。确定未发送单列，不保留为未知调用。
- 金额为 USD，1 USD = 10^12 picoUSD。API 使用整数字符串，SQLite 投影精确累加、前端字符串格式化，避免 JavaScript 和 SQLite 整数合计溢出导致精度损失。

## 实际采购金额的边界

目前账本只有 `procurement_cost_pico` / `procurement_status` 占位字段，没有采购凭证表、可核验的 receipt ID 或采购入账链路。因此 `actual_procurement_cost_pico` 始终为 null，界面显示未核实。即使占位金额不为空或状态写着 confirmed，也不足以证明真实采购金额；它们只计入未核采购金额记录数。

模型响应 ID 是用量证据，不是采购账单。官方参考成本与内部 1/35 估算均不能冒充实际采购。真实采购统计需后续明确凭证来源、币种、分摊和更正审计后接入，不在此只读交付中发明金额。

## 验证与集成

合成 SQLite 测试覆盖管理员鉴权、过滤/分页、UTC边界、迟到凭证归期、金额精度、未知与未定价状态、缺失 token 明细、无凭证采购金额、敏感字段不输出和源账本不变。源码修改需重新生成 OpenAPI/SDK。

本次无需数据库迁移；新增独立 route、SQLite projection、DTO、前端模块及导航。`bootstrap.py` 只新增报表装配；App/PageShell 新增成本路由。与订阅和 Docs 并行整合时应保留双方新增内容并从最终后端重生契约，不能覆盖较新的 main 文件。

真实浏览器和上线验证需在发布环境完成。本轮云端浏览器访问 localhost 被平台 ERR_BLOCKED_BY_CLIENT 拦截，Vite 全地址监听出现 uv_interface_addresses 权限错误；合成单元/组件测试不能替代浏览器或线上验收。
