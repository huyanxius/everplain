# 在 Mac 上验收这次修订

这次从你已编译、安装并体验过的 Library v1 恢复后继续开发，保留了本机修正。包内旧 `macos-build.log` 和 `verification/LOCAL-MAC-VALIDATION.txt` 仅证明 v1 当时的结果。**新增完整功能的这次修订尚未用 Apple SDK 编译、打开或截图验收。**

## 编译与打开

解压后保留 `macos/`、`contracts/`、`tokens/`、`shared-tests/` 的相邻关系。Mac 需要 macOS 13+、Xcode 15+ / Swift 5.9+。

```bash
cd macos
./scripts/build-app.sh release 2>&1 | tee revision-build.log
open .build/Everplain.app
```

也可用 Xcode 打开 `Package.swift`。脚本先检查源码与原素材、跑核心测试，再生成本地未签名 `.app`，并复制必要资源。它不会签名、公证、上传或发布。所有 Swift 依赖已随源码保留。

默认连接与 Web 一致的 `https://e.qunxue.xyz`，登录页只保留原产品邮箱/密码流程。若使用本机开发后端，先通过环境变量指定根地址（不带 `/api`），再编译 debug；release 只接受 HTTPS，debug 的 HTTP 只接受 localhost/127.0.0.1。

## 建议按这个顺序逐项核对

1. 登录/注册：七个错峰运动的原头像、邮箱第一步、密码显示/隐藏、返回、验证码与错误；首次伙伴引导的导入、角色、问卷、完成与跳过。
2. 原有页面：侧栏账户胶囊与通知、经典/分栏导航；首页 Bot、问候、最近研究/资料；同一个输入框转入对话，中文输入法不应掉焦，Return 与 Shift-Return 区分。
3. 对话：300 点自绘模型面板、模型及强度双摘要、六档滑杆、文件和知识库选择；发送飞行、Bot 状态、工作过程、逐字显色、引用/来源；普通和深度研究的明确澄清/计划确认、停止和重试。
4. 账户/伙伴：原弹窗和侧栏结构、Soul/Memory 保存、八个设置面板、用量分页、真实额度、会话和版本冲突。设置与伙伴侧栏打开时后台回答应继续，键盘不能进入被遮盖页面。
5. 知识库/图谱：添加资料、真实导入来源、文件卡、原文定位/搜索、右栏内知识编辑、图/点切换、节点和依据；只读库权限、邀请加入/退出、公开发布的明确确认。
6. 研究：项目/全部文件/记忆；新建、材料、分析、理论、方法、文稿、归档七工具；跨项目时不能把旧对话/章节带到新项目。文稿/方法冲突保留草稿，版本恢复和导出使用真实数据。
7. 导出：Markdown/JSON、ZIP、原生 PDF/Word 和 CSL 引用。打开生成文件检查中英文、段落、页边距、参考文献和警告；自定义 Web CSS 中没有原生等价的规则必须明确提示。
8. 退出/换账户：旧文本、文件、弹窗标题、一次性绑定码、恢复记录不能出现在另一个账户。弱网、失败、取消与快捷切换后不能重复发送或自动重新计费。

只在真实 Mac App 上截图。对齐 Web 与 App 的窗口尺寸，检查浅/深色、最小窗口、展开/收起侧栏、键盘与 Reduce Motion。字体、原生文字排版和视觉动效仍需实际对照，本包不声称截图已经一致。

## 停止恢复的服务端前置

`backend-lookup/native-run-lookup.patch` 提供额外的 owner-scoped 只读查询接口，尚未部署。应通过现有后端维护流程审阅验证；不要把整个候选后端覆盖到生产。

服务端结果未知时，“结束本次等待”仅解除本机等待，不代表服务器已停止。原请求按账户保留，可稍后核对；不会自动重发。明确新建另一对话才创建新请求。

如果编译或运行失败，保留 `revision-build.log`、触发步骤及真实 App 截图。反馈前确认不含密码、Cookie、绑定密钥或其他凭证。
