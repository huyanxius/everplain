# Account and welcome icons

These are exact regular SVG outlines from `@phosphor-icons/core@2.1.1`, verified
byte-for-byte against path values in the actual Web dependency
`@phosphor-icons/react@2.1.10` definitions. Both packages are MIT licensed.
The app draws their geometry in native SwiftUI paths in `AccountSourceIcons.swift`.
No SVG WebView, remote image, SF Symbol approximation, or runtime download is used.

Official package sources:
- https://registry.npmjs.org/@phosphor-icons/core/-/core-2.1.1.tgz
- https://registry.npmjs.org/@phosphor-icons/react/-/react-2.1.10.tgz

Names: ChatsCircle, Shield, UserGear, BookmarkSimple, Folder, TelevisionSimple, Note.
