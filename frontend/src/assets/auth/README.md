# Authentication provider marks

Official provider assets retrieved on 2026-10-05. The files retain the supplied shapes and colors; the UI preserves each mark's aspect ratio and places it to the left of the provider's action label. All trademarks belong to their respective owners.

- `google.png`: the current gradient G, unchanged from [Google Identity's branding guide](https://developers.google.com/identity/branding-guidelines), [original image](https://developers.google.com/static/identity/images/g-logo.png).
- `github.svg` and `github-white.svg`: unchanged `GitHub Logos/SVG/GitHub_Invertocat_Black.svg` and `GitHub Logos/SVG/GitHub_Invertocat_White.svg` from the [official GitHub logo bundle](https://brand.github.com/GitHub_Logos.zip), linked by the [GitHub Brand Toolkit](https://brand.github.com/foundations/logo). The matching black or white asset follows the app's resolved color scheme.

These marks identify optional Google and GitHub authentication actions and explicit account binding. They do not imply endorsement of Everplain.
